UniCareer is a web-based system that helps university students understand their skills and prepare for suitable careers.

Features

Identify skills gained from university subjects.
Record current skills and skill levels.
Automatically recommend suitable careers.
Identify skill gaps.
Generate Learn → Practice → Build roadmaps.
Track roadmap progress.

Technology

Frontend: React, JavaScript, CSS
Backend: Google Apps Script
Database: Google Sheets
Design: Figma
